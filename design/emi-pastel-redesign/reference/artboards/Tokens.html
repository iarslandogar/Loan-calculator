Direction · “Soft ledger”

Calm pastels for the surfaces, deep plum ink for every number.

Borrowing is stressful; the screen shouldn’t be. Lavender, mint, peach and butter are used only as soft backgrounds that tell you which part you’re looking at: mint holds the monthly payment, peach means “recalculate”, butter is a side note, rose means remove. Every word and figure stays a near-black plum, so pastel never costs legibility in a showroom or in front of a customer. In dark mode the same hues sink to deep, low-glare tints, so it stays restful in a dim room.

Pastel roles

Lavender: primary action, focus

Mint: monthly payment, final 0.00

Peach: stale results

Butter: rounding note

Rose: invalid field, Clear, failure

Wash: idle prompt, table header

Space, radius, depth

  • Spacing scale: 4 · 8 · 12 · 16 · 20 · 24 · 28 · 40 px
  • Page padding: 40 desktop · 24 tablet · 16 phone
  • Radii: cards 28 (22 phone) · tiles 20 · inputs 14 · buttons pill 999
  • Borders: 1 px --border cards; 1.5 px --input-border controls; 2 px --error when invalid
  • Elevation: one soft lilac shadow on cards; dialog only gets a deep shadow + blurred plum scrim
  • Controls: 48 px min height (44 required)
  • Motion: none needed; if added, 120 ms colour fades under prefers-reduced-motion: no-preference only

Layout notes

  • ≥ 769 px: grid 4fr / 6fr, gap 24, max 1200 centred. Saved spans both; entries in an auto-fill grid (min 340).
  • ≤ 768 px: one column, gap 16, header stacks, Theme select full width, figures stack 1-up.
  • 180 px (200% zoom): hero drops to 30 px via clamp(30px, 9vw, 48px); groups wrap after commas; tenure row stacks below 300 px; entry buttons wrap.
  • Very wide: content stays capped at 1200; page background fills.
  • Schedule: max-height: min(60vh, 480px), sticky header; on narrow screens the Month column is also sticky while the table scrolls sideways.
